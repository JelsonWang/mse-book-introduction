# MSE Book：材料科学基础考研助手

`mse-book` 是一个面向材料类专业考研的 Agent Skill，基于胡赓祥、蔡珣、戎咏华编著的《材料科学基础（第三版）》构建。它将教材内容整理为可按需调用的概念框架、解题流程、心智模型、易错点、例题和复习工具，帮助学习者从“记住知识点”进一步走向“会判断、会推导、会答题”。

本技能使用 [book-to-skill](https://github.com/virgiliojr94/book-to-skill) 项目提供的文档转技能工作流生成，并针对扫描版教材进行了本地 OCR、章节校正、结构化整理和安全检查。

## 主要功能

### 1. 概念讲解

可以按零基础、教材式、考研简答题或深入推导等不同层次，解释材料科学中的概念。例如：

```text
$mse-book 用零基础能听懂的方式解释位错和柏氏矢量。
```

```text
$mse-book 从热力学和动力学两个角度解释为什么会发生再结晶。
```

### 2. 计算题与读图题

技能可以识别题型、选择公式、列出计算步骤并检查物理意义，主要包括：

- 晶向、晶面、米勒指数与晶面间距；
- 晶体结构、配位数、致密度和滑移系；
- Schmid 因子与临界分切应力；
- 菲克第一、第二定律及 Arrhenius 关系；
- 二元相图、杠杆定律、共晶/包晶/共析反应；
- 三元成分三角形、共轭线和重心法。

```text
$mse-book 根据我上传的二元相图，计算指定合金在该温度下的相组成和相含量。
```

### 3. 结构—工艺—性能分析

分析题会沿以下因果链展开：

```text
工艺参数 → 温度/时间/应力路径 → 扩散或相变
→ 缺陷、晶粒、相和组织变化 → 主导机制变化 → 性能结果
```

适合分析冷加工、退火、淬火、时效、细晶强化、固溶强化、析出强化、凝固偏析以及电热磁光性能等问题。

### 4. 考研简答题与答题模板

可以按题目分值和字数要求生成答案，提供关键词得分点、分点结构、常见遗漏和满分示例。

```text
$mse-book 分别给出“影响再结晶温度的因素”这道题的3分、5分和10分答案。
```

### 5. 出题、自测与批改

可以按章节、难度和题型生成选择、判断、名词解释、简答、计算和综合分析题，也可以在提交答案后评分、指出知识漏洞并生成针对性练习。

```text
$mse-book 给我出一套第7章测试题，暂时不要答案。我提交后按考研标准批改。
```

### 6. 概念辨析与对比

可以将易混概念整理为表格、判断规则或记忆口诀，例如：

- 回复、再结晶与晶粒长大；
- 相、组织和组织组成物；
- 共晶、共析、包晶和包析；
- 形核—长大与调幅分解；
- 马氏体与贝氏体；
- 软磁材料与硬磁材料。

### 7. 跨章节知识链

技能可以把教材中的分散知识连接起来，例如：

- 键合 → 晶体结构 → 材料性能；
- 点缺陷 → 扩散 → 相变；
- 位错 → 塑性变形 → 强化；
- 冷加工 → 储存能 → 回复与再结晶；
- 相图 → 凝固路径 → 显微组织；
- 固溶处理 → 淬火 → 时效 → 析出强化；
- 能带 → 载流子 → 电学和光学性能。

### 8. 复习规划与记忆辅助

可以根据考试日期、每天可用时间、当前基础和薄弱章节，生成多轮复习计划；也能制作背诵提纲、问答闪卡、口诀、一页纸总结和考前速查表。

```text
$mse-book 距离考试还有120天，每天学习2小时，为我制定三轮复习计划。
```

### 9. 结合外部资料学习

可以同时使用目标院校考试大纲、历年真题、课件、课堂笔记、相图图片、错题和个人答案，完成：

- 分析历年真题的章节分布和重复考点；
- 根据考试大纲确定章节权重；
- 检查笔记是否存在知识缺口；
- 按目标院校风格出题和批改；
- 根据错题动态调整复习重点。

## 知识范围

技能覆盖教材十章：

1. 原子结构与键合；
2. 固体结构；
3. 晶体缺陷；
4. 固体中原子及分子的运动；
5. 材料的形变和再结晶；
6. 单组元相图及纯晶体凝固；
7. 二元系相图和合金的凝固与制备原理；
8. 三元相图；
9. 材料的亚稳态；
10. 材料的功能特性。

## 推荐提问格式

```text
$mse-book + 具体章节或题目 + 学习目标 + 希望的输出格式
```

完整示例：

```text
$mse-book 我正在准备材料专业考研。请按照“概念解释—公式—典型题—易错点—5道自测”的结构带我学习第4章扩散。
```

在 ChatGPT 桌面版中，也可以使用 `@mse-book` 显式调用。

## 准确性与使用边界

- 本技能保存的是结构化学习资料，不是原书逐字全文；
- 原始教材为扫描版，复杂公式、上下标、晶体学指数、图中数值和材料牌号应回到原书核对；
- 缺少相图图片或端点数据时，应使用符号解，不能可靠计算具体数值；
- 若用于特定院校备考，建议同时提供考试大纲和历年真题；
- 技能可以生成复习计划，但不会自动记录每日完成情况，除非另行配置任务或提醒。
