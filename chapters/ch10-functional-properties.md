# 第10章 材料的功能特性

## Core Idea｜核心思想

功能特性是材料对外场的响应：电场驱动电荷，温度梯度传递能量，磁场重排磁矩，电磁波与电子能级相互作用。统一分析框架是：**可参与响应的载流子/自由度有多少 → 它们怎样被外场驱动 → 缺陷和热振动怎样散射或阻滞 → 宏观响应量如何定义**。

## Frameworks Introduced｜核心框架

### 1. 外场响应四步法

1. 指明外场与通量：电场—电流，温度梯度—热流，磁场—磁化，光场—吸收/反射/透射。
2. 找微观载体：电子、空穴、离子、声子、磁矩或光子激发。
3. 判定载体数目和迁移能力由何决定：能带、温度、杂质、缺陷、晶界、频率。
4. 写出宏观本构关系并解释材料类别差异。

### 2. 能带—性能链

原子能级在固体中展宽为能带，能带之间为禁带。费米能级及其附近是否有可占据空态，决定电子能否在小外场下改变状态。

- 部分填充能带或价带/导带重叠：金属导电。
- 较窄禁带：热或光可激发电子—空穴对，为半导体。
- 较宽禁带：常温载流子极少，为绝缘体。
- 光子能量 `hν` 与带隙、杂质能级或原子能级匹配时，发生选择性吸收或发射。

## Key Concepts｜关键概念

### 电学性能

基本关系：`J=σE`，`ρ=1/σ`，样品电阻 `R=ρL/A`。单一电子载流子的电导率可写为 `σ=neμe`；半导体通常写成 `σ=e(nμn+pμp)`。载流子浓度 `n、p` 与迁移率 `μ` 是两条独立调控路径。

金属中载流子浓度变化不大，温度升高使晶格振动增强、电子散射增加，电阻率通常上升；杂质、位错、晶界也会增加残余电阻。半导体升温则显著增加热激发载流子数，常使电导率上升。施主掺杂产生 n 型，受主掺杂产生 p 型；高温时本征激发重新占主导。

绝缘体的重点不只是不导电，还包括介电极化。电子、离子、取向和空间电荷极化具有不同响应时间；频率升高时慢机制来不及响应，介电常数会发生色散，并伴随介电损耗。

### 热学性能

- 热容反映材料升温时储存能量的能力；声子和电子均可贡献。
- 热膨胀源于原子势能曲线的非对称性：温度升高后平均原子间距增大。
- 热传导由电子和声子承担。金属电子贡献大；非金属主要靠声子。缺陷、界面、杂质和高温非谐振动会缩短平均自由程、降低导热率。
- 受约束热膨胀或温度梯度会产生热应力。完全约束的一维近似为 `σth≈EαΔT`；是否开裂还取决于强度、韧性、几何和热冲击条件。

### 磁学性能

磁化强度 `M` 表示单位体积磁矩，磁化率 `χ=M/H`；磁感应强度常写为 `B=μ0(H+M)`。按磁矩来源和耦合可分为抗磁、顺磁、铁磁、反铁磁与亚铁磁。

铁磁体由磁畴构成，外场下通过畴壁移动和磁矩转动磁化，产生磁滞。软磁材料要求低矫顽力、低磁滞损耗和高磁导率，宜让畴壁容易移动；硬磁材料要求高矫顽力和高剩磁，需要强磁晶各向异性及有效钉扎。居里温度以上，热扰动破坏长程铁磁有序。

### 光学性能

入射能量满足 `R+A+T=1`（反射率、吸收率、透射率）。折射来自光在介质中相速度改变，折射率 `n=c/v`；界面折射遵循 Snell 定律。金属因大量自由电子与光耦合，在可见光区通常高反射且不透明；非金属的透明窗口取决于带隙、允许跃迁、杂质、孔隙和散射中心。

当光子能量超过带隙可引发带间吸收；电子从激发态回落产生发光。若实现粒子数反转并用谐振腔反馈，受激发射可导致光放大，这是激光的基础。颜色来自可见光谱中选择性吸收、反射或发射，不能只归因于单一“本征色”。

## Mental Models｜心智模型

- **载流子 × 迁移率**：导电强弱既看“有多少能动”，也看“动得多容易”。
- **能带是交通规则，缺陷是路障**：前者决定能否通行，后者决定散射程度。
- **频率是时间尺**：外场变化越快，慢极化、畴壁或热过程越跟不上。
- **功能与结构同源**：成分、缺陷、晶粒和界面既改变力学性能，也改变电、热、磁、光响应。

## Anti-patterns｜常见误区

- 把电阻 `R` 与电阻率 `ρ` 混为一谈，忽略尺寸因素。
- 认为所有材料升温后电阻都上升；金属与本征半导体的主控因素不同。
- 只用带隙区分导体、半导体、绝缘体，不看费米能级与能带填充。
- 把高磁导率等同于永磁性能好；软磁和硬磁指标相反。
- 认为透明材料完全不吸收、不反射；透明只说明特定波段透射占优。
- 用“缺陷越少性能越好”概括功能材料；掺杂和界面常是功能设计手段。

## Worked Example｜温度效应对比

题问：为什么纯金属与本征半导体升温后电阻率趋势常相反？

1. 从 `σ=neμ` 出发。
2. 金属的 `n` 近似不变；升温增强声子散射，使 `μ` 降低，所以 `σ` 降低、`ρ` 上升。
3. 本征半导体的迁移率也会因散射降低，但跨带隙热激发使 `n=p` 指数式增加，载流子浓度效应通常占优，所以 `σ` 上升、`ρ` 下降。
4. 因此不能仅说“热振动变强”，必须比较载流子浓度和迁移率两项的相对变化。

## Key Takeaways｜考研要点

1. 功能响应统一由载体数目、驱动力、迁移/转动能力和散射决定。
2. 金属、半导体、绝缘体的根本差别在能带填充与禁带宽度。
3. 热膨胀来自势能非谐性；热导受电子/声子及散射控制。
4. 软磁追求易磁化低损耗，硬磁追求抗退磁和高剩磁。
5. 光学题先用 `R+A+T=1` 做能量守恒，再判断能带跃迁、自由电子响应与散射。
