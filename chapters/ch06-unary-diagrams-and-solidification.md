# 第6章：单组元相图及纯晶体的凝固

## Core Idea

相图回答“平衡时存在哪些相”，凝固理论回答“新相怎样形成”。纯晶体从液态转变为固态必须先有过冷提供体积自由能驱动力，再克服新界面的能垒形成临界晶核，随后由界面结构、热流和原子迁移共同决定长大方式与最终组织。

## Frameworks Introduced

- **吉布斯相律**
  - 一般体系：`F=C-P+2`；凝聚体系压力固定时：`F=C-P+1`。
  - When to use：判断某相区、两相线或三相点可独立改变的变量数，而不是计算相含量。
- **相变自由能判据**
  - 恒温恒压下自发过程使 Gibbs 自由能降低；两相平衡时化学势/摩尔自由能相等。
  - 纯物质在熔点处液固自由能相等；凝固需 `T<T_m`，即存在过冷度 `ΔT=T_m-T`。
  - 小过冷近似下，单位体积驱动力绝对值随 `ΔT` 增大而增大。
- **经典形核能垒框架**
  - 球形晶胚自由能：`ΔG(r)=4πr²γ+(4/3)πr³ΔG_v`，其中 `ΔG_v<0`。
  - 临界半径 `r*=-2γ/ΔG_v`；形核功 `ΔG*=16πγ³/(3ΔG_v²)`。
  - 过冷度增大 → `|ΔG_v|` 增大 → `r*` 和 `ΔG*` 降低 → 形核更容易。
- **均匀/非均匀形核比较**
  - 非均匀形核借助型壁、夹杂和已有界面，以润湿角相关几何因子降低形核功；实际凝固通常由它主导。
  - 良好形核剂既要降低界面能，还要有合适晶格匹配、稳定性和分散状态。
- **界面结构—长大方式映射**
  - 粗糙界面有大量可接纳原子的台阶位置，可连续长大。
  - 光滑界面需要形成二维晶核或依靠螺型位错提供持续台阶，常呈小平面长大。
  - 最终形貌还受液相温度梯度、潜热排出与界面稳定性影响，不能只由界面微观结构决定。
- **形核率与长大率竞争**
  - 小过冷时形核少而长大相对充分，易得粗晶；较大过冷提高形核密度，通常细化晶粒。
  - 极大过冷时原子迁移率下降，长大甚至形核速率也可能降低，二者都不是无限单调增加。
- **Avrami 动力学**
  - 等温转变量可用 `X(t)=1-exp(-kt^n)` 表示；`n` 综合形核方式和生长维数，`k` 反映温度相关速率。

## Key Concepts

- **组元**：构成体系且可独立表达组成的最少化学成分。
- **相**：物理化学性质均匀、与其他区域由界面分开的部分。
- **自由度**：不改变平衡相数时可独立变化的强度变量数。
- **过冷度**：理论熔点与实际凝固温度之差，是凝固驱动力的重要表征。
- **晶胚与晶核**：小于临界尺寸的晶胚不稳定；超过临界尺寸后长大可降低总自由能，成为稳定晶核。
- **形核率**：单位体积、单位时间形成稳定晶核的数目。
- **动态过冷度**：维持液固界面推进所需的界面过冷。
- **结构起伏**：液体短程有序原子团不断形成和消失的现象。
- **小平面/非小平面晶体**：分别常对应微观光滑/粗糙界面及不同长大机制。
- **球晶**：高分子片晶分支并径向生长形成的聚集结构。

## Mental Models

- **新相形成要同时付“体积账”和“表面账”**：体积自由能随晶核体积降低，界面能随面积增加；两者竞争产生临界尺寸。
- **过冷既提供驱动力，也改变动力学**：增大过冷通常促进形核，但温度太低会降低原子迁移率。
- **细化晶粒有两条路**：增加有效形核数，或抑制已有晶核长大；实际孕育处理常同时利用两者。
- **相图是终点地图，动力学是行驶速度**：相图给出平衡可能性，不保证在实际冷速与时间内到达。

## Anti-patterns

- **用相律计算各相百分数**：相律只给自由度；相含量要用质量守恒或杠杆法则。
- **认为达到熔点就会自动完全凝固**：熔点处液固自由能相等，没有净凝固驱动力。
- **认为任意晶胚都会长大**：小于 `r*` 的晶胚长大会增加自由能，倾向于消失。
- **把非均匀形核理解为改变临界半径**：在经典球冠模型中，基底主要通过几何因子降低形核功；曲率半径仍由体积驱动力和界面能决定。
- **只用冷速解释晶粒尺寸**：还要考虑形核剂、界面能、温度梯度、溶质和热流条件。

## Worked Example

解释“加入少量形核剂并提高冷却速度可细化晶粒”：

1. 形核剂提供低能异质界面，降低非均匀形核功，使更多位置在较小过冷度下成为稳定晶核。
2. 提高冷速通常增加实际过冷度，使体积自由能驱动力增大，临界晶核尺寸和形核能垒降低。
3. 更多晶核同时竞争有限液相空间，每个晶粒可长大的距离减小，因此组织细化。
4. 但冷速过高可能引入温度梯度、非平衡缺陷或玻璃化；形核剂若团聚、反应或晶格失配，也不能有效细化。

## Key Takeaways

1. 相律用于数自由度；自由能判据用于判断相变方向；形核理论用于判断新相能否出现。
2. 凝固需要过冷，过冷度通过降低 `r*` 和 `ΔG*` 促进形核。
3. 实际材料通常非均匀形核，形核剂作用可从界面能、润湿和晶格匹配解释。
4. 晶体长大方式受界面结构控制，组织形貌还受热流和界面稳定性控制。
5. 晶粒尺寸由形核率与长大率竞争决定，不应只背“冷速快、晶粒细”的结论。
6. 高分子结晶同样经历形核与长大，但链规整性、柔顺性和迁移缓慢使结晶常不完全并具有熔限。
