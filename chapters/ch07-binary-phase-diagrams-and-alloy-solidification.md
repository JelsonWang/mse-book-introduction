# 第7章 二元系相图和合金的凝固与制备原理

## Core Idea｜核心思想

二元相图把“温度—成分—平衡相”压缩到一张图中。解题时不要靠背图形，而要沿固定链条推理：**定状态点 → 判相区 → 作水平连线 → 读各相成分 → 用杠杆定律求量 → 沿成分垂线追踪冷却 → 写不变反应与最终组织**。相图给出平衡极限；真实凝固组织还取决于形核、扩散、界面稳定性与冷速。

## Frameworks Introduced｜核心框架

### 1. 二元相图六步法

1. 标出合金总成分 `C0` 与温度 `T` 的状态点。
2. 识别单相、两相或三相不变反应线。
3. 两相区内作等温线（tie line），端点给两相平衡成分 `Cα、Cβ`。
4. 由杠杆定律求相分数：

   `fα = (Cβ - C0)/(Cβ - Cα)`，`fβ = (C0 - Cα)/(Cβ - Cα)`。

5. 沿 `C0` 垂线降温，记录每次穿越液相线、固相线、溶解度线或水平反应线的变化。
6. 分开回答“有哪些相、各相多少”和“有哪些组织组成物、各占多少”。

### 2. 热力学读图法

在给定温度下，以各相的摩尔自由能—成分曲线比较稳定性。两相平衡由两条自由能曲线的**公切线**确定：切点给平衡成分，相同斜率对应组元化学势相等。规则溶液中的相互作用参数可作方向判断：`Ω < 0` 倾向异类原子结合和有序化，`Ω > 0` 倾向同类聚集并可能出现互溶间隙，`Ω = 0` 接近理想混合。

### 3. 凝固的三层判断

- **平衡路径**：固、液相均充分扩散，瞬时成分始终落在固相线和液相线端点。
- **非平衡路径**：液相混合较快、固相扩散很慢，先后形成的固相成分不同，产生枝晶偏析或晶内偏析。
- **界面稳定性**：固液界面前沿若因溶质富集形成成分过冷，平面界面会失稳，转为胞状或枝晶生长。

## Key Concepts｜关键概念

### 相律、相区与自由度

定压二元系相律为 `F = C - P + 1 = 3 - P`。单相区 `F=2`，可独立改变温度和成分；两相区 `F=1`，温度一旦给定，两相成分随之确定；三相共存时 `F=0`，反应温度和三相成分均固定。因此二元三相平衡表现为水平线。

### 典型不变反应

| 类型 | 冷却时反应 | 识别与要点 |
|---|---|---|
| 共晶 | `L → α + β` | 一个液相同时生成两个固相；共晶组织是组织组成物 |
| 包晶 | `L + α → β` | 新相常包覆初生相，固态扩散慢时反应不完全 |
| 共析 | `γ → α + β` | 全固态反应，典型如奥氏体形成珠光体 |
| 包析 | `α + β → γ` | 两个固相生成一个固相，动力学通常更慢 |
| 偏晶 | `L1 → L2 + α` | 液态存在互溶间隙 |

同晶型相图只有液相与连续固溶体；含有限固溶度的共晶/包晶图还要关注低温溶解度下降导致的二次析出。遇稳定中间化合物，可先以化合物成分线为界，把复杂相图拆成若干较简单子图。

### 相分数与组织组成物分数

“相”由结构和成分定义；“组织组成物”由形成历史定义。共晶以下可能只有 `α、β` 两相，却同时含初生 `α` 与共晶组织 `(α+β)`。求共晶组织量，应在共晶温度**略上方**求剩余液相量；求最终 `α、β` 相量，应在目标温度用该温度的连线重新计算。两者不可混用。

### Fe–Fe₃C 图的通用读法

先判合金属于亚共析、共析或过共析范围；再沿成分垂线追踪奥氏体区边界。缓冷后，亚共析钢为先共析铁素体 + 珠光体，过共析钢为先共析渗碳体 + 珠光体。珠光体是铁素体和渗碳体的共析组织，不是单一相。

## Mental Models｜心智模型

- **相图是地图，不是行程记录**：它告诉你平衡终点和边界，实际是否到达取决于扩散时间。
- **水平线称成分，线段称质量**：两相区端点读成分，反向线段比给分数。
- **跨线即发生事件**：沿成分垂线每跨一条边界，都要问“新相何时出现、旧相何时消失、成分如何变化”。
- **先热力学、后动力学**：先回答“允许什么”，再回答“实际形成什么”。

## Anti-patterns｜常见误区

- 把横坐标的质量分数与原子分数直接混算。
- 用总成分 `C0` 当作两相区中任一相的成分。
- 杠杆定律“同侧线段比同侧相”；正确是**反向杠杆**。
- 跨越共晶线后仍沿用共晶温度上方的相分数。
- 把共晶、珠光体等组织组成物写成一个相。
- 看到相图就默认实际组织完全平衡，忽略偏析、包晶反应不完全和冷速效应。

## Worked Example｜典型例题

某共晶系在共晶温度 `TE` 时，`CαE=20%`、`CE=60%`、`CβE=90%`，合金 `C0=40%`。

1. `TE` 略上方处于 `α+L`：
   - 初生 `α` 分数 `=(60-40)/(60-20)=0.50`；
   - 剩余液相分数 `=(40-20)/(60-20)=0.50`。
2. 冷却穿过 `TE`，全部剩余液相变成共晶组织，因此共晶组织分数为 `0.50`。
3. `TE` 略下方总相分数：
   - `fα=(90-40)/(90-20)=0.714`；
   - `fβ=(40-20)/(90-20)=0.286`。

结论：共晶组织占 `0.50`，但总 `α` 相占 `0.714`。这正是“组织组成物分数 ≠ 相分数”的典型情形。

## Key Takeaways｜考研要点

1. 两相区：水平连线读成分，杠杆定律求相量。
2. 二元三相平衡自由度为零，故不变反应位于水平线。
3. 相量、初生相量、共晶/共析组织量必须在相应温度分别计算。
4. 非平衡凝固的根源是固态扩散来不及，典型结果是偏析与包晶反应不完全。
5. 成分过冷把溶质分配、温度梯度与枝晶形貌连成一条因果链。
