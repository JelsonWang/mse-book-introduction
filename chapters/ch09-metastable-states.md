# 第9章 材料的亚稳态

## Core Idea｜核心思想

亚稳态不是“没有稳定性”，而是体系被能垒困在局部自由能低谷：自由能高于平衡态，却能在有限时间内存在。材料工程的本领，常在于通过快冷、形变、机械合金化或热处理控制**驱动力—能垒—扩散时间**，把纳米晶、准晶、非晶、过饱和固溶体、马氏体或贝氏体等非平衡结构保留下来并利用其性能。

## Frameworks Introduced｜核心框架

### 1. 亚稳态四问

1. 平衡态是什么，当前状态为何自由能更高？
2. 转变要跨越什么能垒（界面能、应变能、形核功）？
3. 原子需要长程扩散、短程扩散，还是协同切变？
4. 温度—时间路径是否给了转变足够机会？

### 2. 亚稳结构分类

| 类型 | 结构特征 | 形成路径 | 核心控制量 |
|---|---|---|---|
| 纳米晶 | 晶粒 <100 nm，界面体积分数大 | 强塑变、气相沉积、机械合金化、非晶晶化等 | 晶粒尺寸、界面状态 |
| 准晶 | 长程取向有序，无平移周期；可有五/十/十二次对称 | 快速凝固或特定合金反应 | 成分、冷速、竞争相 |
| 非晶 | 无长程周期有序 | 熔体急冷、沉积、辐照、球磨等 | 临界冷速、玻璃形成能力 |
| 脱溶产物 | 过饱和固溶体析出第二相 | 固溶处理 + 淬火 + 时效 | 形核、扩散、共格应变 |
| 马氏体 | 无扩散、协同切变，成分近似不变 | 快速冷却越过 `Ms` | 化学驱动力与晶格应变 |
| 贝氏体 | 铁素体 + 碳化物复相组织 | 中温等温/连续冷却 | 碳扩散与晶格切变耦合 |

### 3. 固态相变判别树

- 新旧相成分明显改变且需原子迁移：优先按扩散型相变分析。
- 成分基本不变、形状应变显著、界面高速推进：按马氏体型无扩散转变分析。
- 过饱和固溶体自由能曲线满足 `∂²G/∂c² < 0`：微小成分起伏可自发放大，为调幅分解。
- 若需先形成临界晶核：是形核—长大型脱溶，通常有孕育期。

## Key Concepts｜关键概念

### 纳米晶：界面主导

晶粒降至纳米尺度后，大比例原子位于晶界或三叉晶界，其配位、密度和化学成分偏离晶内。因而性质不能只由“更细晶粒”外推：表面/界面效应、小尺寸效应、量子尺寸效应及偏聚会共同作用。Hall–Petch 关系在一定细化范围内体现晶界阻碍位错；进入极小尺寸后，变形机制可能转向晶界滑移、扩散或旋转，简单线性外推会失效。

### 准晶：有序但不周期

准晶具有长程有序和特定旋转对称，却不具普通晶体的三维平移周期。它可用非周期拼砌或高维投影理解。典型性能来自独特电子结构与界面：较高硬度、低摩擦、较低导电/导热等，但具体表现依合金组成和缺陷而变。

### 非晶：动力学冻结

液体降至平衡熔点以下本应形核并结晶；若冷速足够快，使体系在结晶前到达玻璃化温度 `Tg` 附近，黏度剧增、原子迁移被冻结，形成非晶。`Tg` 是动力学相关温度，会随冷速变化，不是严格的平衡相变温度。良好玻璃形成能力常与较低液相线温度、多组元、较大原子尺寸差和强负混合倾向有关。

### 脱溶、时效与粗化

固溶处理获得单相，淬火保留过饱和固溶体，时效使弥散析出相形成并强化。析出形态由界面能与弹性应变能竞争决定：球形表面积小，片/针状有时能降低共格应变能。时效过久后，小颗粒因曲率高、平衡溶解度高而溶解，大颗粒长大（Ostwald 熟化），界面总能降低但强化作用常下降。

形核—长大在亚稳区内靠成分起伏跨越能垒；调幅分解在自旋区内通过“上坡扩散”连续放大成分波动，早期无清晰界面。连续脱溶可在晶内均匀发生；不连续脱溶常从晶界生长为层片胞状组织。

### 马氏体与贝氏体

马氏体由母相原子协同位移形成，成分基本不变，具有惯习面、取向关系和表面浮凸；内部亚结构可为高密度位错或孪晶。多数钢中转变量主要随降温增加，以 `Ms、Mf` 标记开始和终了温度；停留时间通常不是主控量。过饱和碳和高缺陷密度带来高强硬度，也提高脆性，故常需回火。

贝氏体在过冷奥氏体中温区形成，是铁素体与碳化物组成的复相组织。上贝氏体常呈羽毛/板条束，碳化物多分布于板条间；下贝氏体中细小碳化物可在铁素体片内析出，通常强韧性更佳。它兼有切变特征与碳扩散，不应简单归为完全扩散或完全无扩散。

## Mental Models｜心智模型

- **能量地形**：稳定态是最低谷，亚稳态是被山垭隔开的次低谷。
- **热处理是时间窗口控制**：高温给扩散速度，低温给驱动力；最佳组织常出现在两者折中处。
- **尺度改变主导机制**：当晶粒、析出物或层片降到纳米级，界面占比和迁移机制都会改变。
- **先问成分是否改变**：这是区分扩散型与无扩散型相变的最快入口。

## Anti-patterns｜常见误区

- 把亚稳态写成热力学稳定态，或认为它一定会立即分解。
- 把 `Tg` 当成与熔点同类、唯一固定的平衡温度。
- 认为任何细晶强化都无限服从 Hall–Petch 关系。
- 把调幅分解描述为经典形核—长大。
- 认为马氏体不扩散就“不需形核”或“不受驱动力影响”。
- 把贝氏体当作单一相；它是复相组织。
- 只说“时效越久越强”，忽略过时效粗化。

## Worked Example｜热处理路径分析

某合金高温为单相固溶体，低温平衡状态为基体 + 第二相。若希望获得弥散析出强化：

1. 在单相区固溶，使溶质充分溶入基体。
2. 快速淬火，抑制扩散，保留过饱和固溶体。
3. 在中温时效：温度过低时扩散慢、孕育期长；温度过高时形核驱动力小且易粗化。
4. 强度随时间通常经历欠时效 → 峰时效 → 过时效。峰值对应粒子尺寸、间距、共格性与位错作用机制的综合最优，而非析出量无限增加。

答题时应同时写出：热力学驱动力来自过饱和自由能差；动力学由形核与扩散控制；过时效由曲率驱动的粗化和共格性降低造成。

## Key Takeaways｜考研要点

1. 亚稳态存在于“有驱动力但能垒/动力学受限”的条件下。
2. 非晶形成是结晶被动力学避开的结果；`Tg` 随时间尺度变化。
3. 调幅分解条件是自由能曲率为负，特征是上坡扩散和连续成分波。
4. 马氏体近似无扩散、协同切变；贝氏体是扩散与切变耦合的复相组织。
5. 析出强化必须结合形核、共格应变、粗化和时效曲线分析。
