# 第8章 三元相图

## Core Idea｜核心思想

三元相图把三个独立成分约束在“总和为 100%”的等边三角形中，再加温度形成空间模型。考研解题的关键不是想象完整立体图，而是明确当前使用的是**成分三角形、等温截面还是垂直截面**，再用相律、连线/共轭三角形与重心法判断平衡。

## Frameworks Introduced｜核心框架

### 1. 三元读图七步法

1. 确认三个顶点分别代表纯 `A、B、C`，三条边分别是二元系。
2. 用过点且平行于对边的线读取相应顶点组元含量，并检查 `xA+xB+xC=100%`。
3. 明确温度条件和截面类型。
4. 用定压相律 `F=C-P+1=4-P` 判断可变参数数目。
5. 单相区直接读相；两相区找共轭线两端；三相区找共轭三角形三个顶点。
6. 用杠杆法或重心法求相分数。
7. 沿冷却路径追踪液相成分轨迹、初生相区边界、共晶谷和不变点。

### 2. 相区的几何对应

| 平衡状态 | 定压自由度 | 等温截面中的几何对象 |
|---|---:|---|
| 单相 | 3 | 面积区域中的任一点 |
| 两相 | 2 | 一族共轭线；总体成分在两相成分连线上 |
| 三相 | 1 | 共轭三角形；总体成分在三相成分三角形内 |
| 四相 | 0 | 不变温度的水平面/不变反应点 |

这里的自由度包含温度；固定温度后再少一个自由度。

### 3. 重心法

若三相成分点为 `Cα、Cβ、Cγ`，总体成分为 `C0`，则有

`C0 = fαCα + fβCβ + fγCγ`，且 `fα+fβ+fγ=1`。

几何上，`C0` 是三个相点以相分数为权重的重心。相分数可用对面子三角形面积比表示：某相的分数等于总体点与另外两个相点形成的子三角形面积，除以整个共轭三角形面积。先确认 `C0` 位于共轭三角形内部；若不在，假设的三相平衡不成立。

## Key Concepts｜关键概念

### 成分三角形

- 顶点：某组元为 100%。
- 对边：该组元为 0%，即另两组元组成的二元系。
- 平行于某一边的直线：其对面顶点所代表组元的含量恒定。
- 三条等含量线可作自检，但只有两个成分独立。

不同教材可能采用顺/逆时针标度，不能仅凭视觉方向判断读数，必须先看顶点和刻度标注。

### 截面与投影

- **等温截面**：固定温度切出的真实平衡图；可直接判断相区并应用连线、重心法。
- **垂直截面**：沿某一成分关系切取，用于观察随温度变化的相区；其水平线通常不等于真实共轭线，不能无条件直接套杠杆定律。
- **液相面投影**：把空间液相面的沟谷、脊线和不变点投影到成分三角形，便于追踪凝固路径。

### 三元凝固路径

合金从液相冷却时，先在所属初生相区析出相；液相成分沿液相面向较低温方向移动。到达两液相面交线/共晶谷后，两个固相与液相共存，液相沿谷线继续移动；到三条谷线汇聚的不变点，可发生四相反应。常见形式包括三元共晶 `L→α+β+γ`、包共晶 `L+α→β+γ` 以及四相包晶 `L+α+β→γ`。反应式必须由进入与离开不变点的相区关系判断，不可只凭箭头外形背诵。

### 稳定化合物与伪二元截面

若存在稳定中间化合物，可把三元体系按连接线分割成若干子体系。只有当某条成分路径上的相平衡可像独立二元系那样闭合时，才可作为伪二元截面处理；普通垂直截面不自动具备这一性质。

## Mental Models｜心智模型

- **三角形是质量守恒图**：任一点就是三个组元配比，坐标和恒为一。
- **两相是一根秤杆，三相是一块承重板**：两相用线段杠杆，三相用重心和面积。
- **空间相图先切片再思考**：先确定截面，再谈连线和相量。
- **液相沿山谷下行**：液相面投影中，剩余液体趋向低温谷线和不变点。

## Anti-patterns｜常见误区

- 三个坐标分别读出后不检查总和是否为 100%。
- 把相区边界线当作两相共轭线；只有实际连接平衡相成分的线才能用于杠杆法。
- 在任意垂直截面上直接用水平线算相分数。
- 三相区仍只做一次一维杠杆计算，忽略第三相。
- 把液相面投影中的投影距离误当真实温度或空间距离。
- 未判断反应前后相的消长，就机械写三元共晶反应式。

## Worked Example｜重心法题型

某温度下总体成分 `C0` 落在 `α、β、γ` 三相共轭三角形内部。

1. 连接 `C0` 与三个相点，将大三角形分成三个子三角形。
2. 设大三角形面积为 `S`：
   - `fα = S(C0,Cβ,Cγ)/S(Cα,Cβ,Cγ)`；
   - `fβ = S(Cα,C0,Cγ)/S(Cα,Cβ,Cγ)`；
   - `fγ = S(Cα,Cβ,C0)/S(Cα,Cβ,Cγ)`。
3. 检查三者均非负且和为 1。
4. 再以三个相分数加权三个相成分，应还原 `C0`。

若题图给出网格，可按底×高或坐标行列式算面积；若 `C0` 恰在一条边上，与其相对的相分数为零，问题退化为两相杠杆定律。

## Key Takeaways｜考研要点

1. 三元定压相律 `F=4-P`；四相共存是不变平衡。
2. 读成分用平行对边法，并以总和 100% 自检。
3. 两相连线用杠杆，三相三角形用重心/面积法。
4. 等温截面可直接表达平衡；普通垂直截面不能随意套杠杆定律。
5. 凝固路径由初生相区、共晶谷和不变点共同决定。
