# 第3章：晶体缺陷

## Core Idea

真实晶体的性能由“偏离理想排列的方式”强烈控制。点缺陷提供扩散载体并改变电学/化学状态，位错把整体刚性滑移转化为局部逐步运动，表面和界面则以高能、低配位区域控制形核、迁移、腐蚀与多晶体强度。

## Frameworks Introduced

- **缺陷按维数分类**
  - 0维：空位、间隙原子、置换溶质及复合点缺陷。
  - 1维：刃型、螺型和混合位错。
  - 2维：外表面、晶界/亚晶界、孪晶界、相界和层错。
  - When to use：先定位缺陷维数，再选择热力学、弹性场或界面能模型。
- **点缺陷自由能平衡**
  - 形成缺陷会提高内能，却增加组态熵；有限温度下自由能极小对应非零平衡浓度。
  - 典型关系为 `C_v = A exp(-Q_f/RT)`；升温使平衡空位浓度按指数规律增大。
  - 淬火、冷变形或辐照可保留超过平衡值的过饱和缺陷。
- **位错几何判别框架**
  - 刃型位错：位错线 `l` 与伯氏矢量 `b` 垂直，存在多余半原子面。
  - 螺型位错：`l ∥ b`，原子面呈螺旋错排。
  - 混合位错：`l` 与 `b` 成一般角度，可分解为刃型和螺型分量。
- **伯氏矢量守恒**
  - 伯氏回路闭合差定义 `b`；它表示位错造成的点阵畸变总累积，也是位错强度和滑移量。
  - 同一连续位错线上 `b` 保持不变；位错节点处各支路伯氏矢量满足矢量守恒。
- **位错运动—塑性框架**
  - 滑移：位错在包含 `l` 与 `b` 的滑移面内运动，引起晶体两侧相对位移 `b`。
  - 攀移：刃型位错通过吸收或放出空位垂直滑移面运动，属扩散控制的热激活过程。
  - 交滑移：螺型位错可转入另一包含其位错线的滑移面。
  - 弗兰克-里德源说明受钉扎位错段如何弯曲、闭合并连续放出位错环。
- **界面能驱动框架**
  - 表面或晶界原子配位不足、能量较高；系统倾向于减小总界面面积或形成较低能界面。
  - 小角度晶界可视为规则位错阵列；相界还需按两侧结构匹配程度区分共格、半共格和非共格。

## Key Concepts

- **肖特基缺陷**：原子离开正常位置到表面，或离子晶体中以满足电中性的空位组合出现。
- **弗仑克尔缺陷**：原子/离子离开正常结点进入间隙，同时形成空位—间隙对。
- **色心**：电子或空穴与离子空位关联形成的电荷缺陷，可改变颜色与电导。
- **位错密度**：单位体积中位错线总长度，常用来表征塑性变形后的缺陷水平。
- **滑移面**：位错发生保守运动的晶面；刃型位错只有一个由 `l` 和 `b` 确定的滑移面。
- **位错线张力**：位错能量随长度增加而增加，使弯曲位错倾向于缩短。
- **层错**：密排层正常堆垛顺序的局部破坏，其边界通常是部分位错。
- **扩展位错**：一个全位错分解为若干部分位错，中间夹有层错带。
- **晶界**：取向不同晶粒之间的界面；具有过剩能、快速扩散和偏聚倾向。
- **相界**：不同相之间的界面，结构匹配程度决定界面能和应变能。

## Mental Models

- **位错像“逐排拉动拉链”**：无需整个滑移面原子同时越过高能势垒，因此实际屈服应力远低于完整晶体理论强度。
- **缺陷既是高能区，也是动力学捷径**：晶界、表面和位错芯处结构疏松，常成为扩散、腐蚀和形核的优先位置。
- **位错反应先做矢量账本**：判断反应能否发生先看伯氏矢量守恒，再比较反应前后 `Σb²`；在相同弹性常数近似下，后者减小通常更有利。
- **部分位错间距是两种作用的平衡**：同号部分位错弹性排斥使其分开，层错能使层错面积缩小；层错能越低，扩展宽度通常越大。

## Anti-patterns

- **把缺陷都当成有害杂质**：点缺陷是扩散和离子导电的必要条件，位错又是塑性变形的载体。
- **认为螺型位错有唯一滑移面**：凡同时包含 `l` 和 `b` 的面都可能成为其滑移面，因此能发生交滑移。
- **把攀移当作普通滑移**：攀移需要点缺陷扩散和物质交换，温度敏感且属于非保守运动。
- **仅凭几何判断位错反应**：几何连通不够，还要满足伯氏矢量守恒并考虑能量变化。
- **混淆晶界与相界**：晶界两侧可为同一相不同取向；相界两侧的相结构或成分不同。

## Reference Tables

| 位错类型 | `l` 与 `b` | 主要应变场 | 运动特点 |
|---|---|---|---|
| 刃型 | `l ⟂ b` | 拉压应变 + 切应变 | 在唯一滑移面滑移；可通过扩散攀移 |
| 螺型 | `l ∥ b` | 纯切应变为主 | 可在多个候选面滑移，能交滑移 |
| 混合型 | 一般夹角 | 刃型与螺型分量叠加 | 沿位错线各处法向推进 |

| 面缺陷 | 结构特征 | 常见影响 |
|---|---|---|
| 外表面 | 原子配位不足 | 吸附、氧化、表面扩散、形核 |
| 小角度晶界 | 位错阵列 | 界面能随错配角增加 |
| 大角度晶界 | 高度错配过渡层 | 快速扩散、偏聚、晶界滑动 |
| 共格相界 | 原子面连续但有弹性错配 | 界面能低、应变能可能高 |
| 半共格相界 | 周期性失配位错释放应变 | 界面能与应变能折中 |
| 非共格相界 | 原子面不连续 | 界面能高、迁移机制复杂 |

## Worked Example

判断位错反应 `b₁ + b₂ → b₃` 是否可能：

1. 把各伯氏矢量写在同一晶格坐标系中，先验证 `b₃ = b₁ + b₂`；不守恒则反应不成立。
2. 在各向同性近似下，位错线能量与 `Gb²` 同量级，比较 `b₁²+b₂²` 和 `b₃²`。
3. 若反应后平方和较小，能量上通常有利；若较大，需要外力或其他能量补偿。
4. 再检查反应产物是否位于允许晶格平移矢量/部分位错集合中，并考虑滑移面几何。

这套步骤避免只凭位错图形“看起来能连接”作判断。

## Key Takeaways

1. 点缺陷平衡浓度由形成能与熵共同决定，并随温度指数增加。
2. 伯氏矢量是位错题的核心不变量：它决定类型、滑移方向、畸变强度和反应守恒。
3. 滑移、攀移、交滑移的适用位错类型与温度条件必须区分。
4. 位错降低开始塑性变形所需应力，但位错间交互和障碍又会造成加工硬化。
5. 表面与界面是高能快速通道，连接扩散、形核、再结晶和相变。
