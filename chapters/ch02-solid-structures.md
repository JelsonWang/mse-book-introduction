# 第2章：固体结构

## Core Idea

固体结构的核心不是背诵晶胞图，而是用“周期性—对称性—配位与堆垛—相结构”描述原子怎样占据空间，再由此判断密度、各向异性、滑移能力和相稳定性。本章把金属、合金、离子/共价晶体、高分子、准晶、液晶和非晶体放入统一的结构比较框架。

## Frameworks Introduced

- **晶格—基元—晶体结构框架**
  - When to use：从重复单元建立晶体几何模型，或区分“点阵”和“真实原子排列”。
  - How：先找具有平移周期性的空间点阵，再给每个点阵点配置相同基元；二者共同决定晶体结构。晶胞是能表达这种周期性的体积单元，原胞强调最小重复体积。
- **晶向/晶面指数算法**
  - 晶向 `[uvw]`：取方向矢量在晶轴上的分量，约成最小整数比。
  - 晶面 `(hkl)`：取各轴截距，以晶格常数为单位求倒数，再化为最小整数。
  - 晶向族 `<uvw>` 与晶面族 `{hkl}` 表示由对称操作联系的一组等价方向或晶面。
- **结构比较四指标**
  - 配位数、原子堆积因子（APF）、单位晶胞原子数、间隙类型共同刻画金属晶体的紧密程度和可容纳原子的位置。
  - 对滑移问题还要结合密排面与密排方向，不能只比较 APF。
- **合金相结构判别**
  - 固溶体保持溶剂晶体结构，可分置换型与间隙型；中间相具有新的结构或有序性，可表现为金属间化合物、电子化合物、尺寸因素化合物等。
  - 置换固溶倾向受原子尺寸、晶体结构、电负性和价电子因素共同影响；间隙固溶要求溶质原子足够小。
- **有序程度连续谱**
  - 晶体：长程周期有序；准晶：长程有序但无三维平移周期；液晶：保留部分取向或位置有序并具有流动性；非晶体：无长程有序但可有短程有序。

## Key Concepts

- **空间点阵**：用几何点抽象晶体平移周期性的模型。
- **晶胞参数**：晶轴长度 `a,b,c` 和夹角 `α,β,γ`，共同描述晶胞几何。
- **配位数**：一个原子最近邻原子数，反映局部堆积。
- **原子堆积因子**：晶胞中原子所占体积与晶胞体积之比。
- **多晶型性**：同一物质随温度或压力改变而具有不同晶体结构。
- **固溶体**：溶质原子进入溶剂晶格且不改变其基本结构形成的单相。
- **有序固溶体**：不同原子在晶格位置上呈长程有序分布的固溶体。
- **配位多面体**：以中心离子和其近邻离子形成的几何多面体，用于描述离子晶体。
- **倒易点阵**：将晶面族映射为倒易空间点的工具，是衍射分析的自然语言。
- **玻璃化温度 `T_g`**：非晶材料由玻璃态向高弹态/过冷液态转变的温区特征，不等同于晶体熔点。

## Mental Models

- **看到结构先问“重复的是什么”**：点阵只表达平移关系，基元才包含元素种类和相对坐标。
- **几何性质与化学性质分层处理**：先算晶面、晶向、配位和间隙，再用键型、半径比和价态判断哪些位置能够稳定占据。
- **衍射是倒易空间问题，形貌是实空间问题**：不要把晶面间距、倒易矢量和真实原子间距混为一谈。
- **“有序”不等于“周期”**：准晶可有清晰衍射斑点和长程有序，但不满足传统平移周期性。

## Anti-patterns

- **把晶格等同于晶体结构**：相同点阵配不同基元可形成完全不同的结构。
- **求晶面指数时忘记取截距倒数**：与某轴平行意味着截距无穷大，其指数为 0。
- **把 HCP 当作立方晶系**：HCP 的方向、晶面和四指数表示有自身规则，不能照搬立方晶系。
- **只以原子半径差判断固溶度**：尺寸是重要条件，但晶体结构、电负性与电子浓度同样可能成为限制因素。
- **把非晶态理解为完全无序**：非晶体通常仍有近程有序，只缺少长程周期性。

## Worked Example

给定立方晶胞中一个平面与三轴截距分别为 `a、∞、a/2`：

1. 以晶格常数为单位，截距写为 `(1,∞,1/2)`。
2. 取倒数得 `(1,0,2)`，已为最小整数，因此晶面指数为 `(102)`。
3. 若判断其等价晶面，应结合该晶体所属点群；在立方晶系中可用轴置换和符号变化构成 `{102}`。
4. 若继续求面间距，代入立方关系得 `d_102=a/√5`。

再比较 FCC 与 BCC：FCC 的 APF 和配位数更高，存在明确密排面与密排方向；但“更密排”不直接等于“更强”，实际强度还由键合、位错阻力、晶粒和合金化决定。

## Key Takeaways

1. 晶体结构题先区分点阵、基元和晶胞，再进行指数或密度计算。
2. FCC、BCC、HCP 的原子数、配位数、APF、密排面/方向是高频成套考点。
3. 合金相结构要区分固溶体和中间相，并用尺寸、结构、电负性和电子因素解释形成倾向。
4. 离子晶体稳定性主要从电中性、配位和离子尺寸几何约束分析；共价晶体还需强调方向性。
5. 晶态、准晶、液晶和非晶态的关键分界是长程有序、平移周期性和流动性。
