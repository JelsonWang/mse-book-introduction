# 第4章：固体中原子及分子的运动

## Core Idea

扩散是由热运动引起、由化学势梯度驱动的原子或分子迁移过程。宏观上用菲克定律描述通量与浓度演化，微观上由空位、间隙或链段运动跨越能垒实现；温度、结构、缺陷和成分共同决定扩散速率。

## Frameworks Introduced

- **菲克定律框架**
  - 第一方程 `J = -D∂c/∂x`：描述稳态或瞬时局部通量，负号表示从高浓度向低浓度扩散。
  - 第二方程 `∂c/∂t = D∂²c/∂x²`：在 `D` 为常数时描述非稳态浓度场随时间变化。
  - When to use：第一方程解决“流过多少”，第二方程解决“分布怎样随时间改变”。
- **化学势驱动框架**
  - 浓度梯度只是常见表象，严格驱动力是化学势梯度；在非理想体系中可出现“上坡扩散”。
  - 多元体系要区分示踪扩散、自扩散、本征扩散与互扩散系数。
- **原子跳跃与阿伦尼乌斯关系**
  - 原子必须获得足够热能越过迁移势垒；扩散系数通常写为 `D = D₀ exp(-Q/RT)`。
  - `D₀` 汇集几何、振动频率和熵项，`Q` 是表观扩散激活能。
- **扩散机制判别**
  - 置换原子多通过空位机制；小原子常通过间隙机制；还可存在直接交换、环形交换以及沿位错/晶界/表面的短路扩散。
  - 机制选择取决于可用缺陷、原子尺寸、局部结构和迁移能垒。
- **扩散距离标度**
  - 随机行走使平均位移尺度满足 `x ~ √(Dt)`；扩散层加深需要时间按距离平方增长。
  - 这是估算渗碳、均匀化退火和薄膜互扩散时间的首要量纲关系。
- **高分子分级运动框架**
  - 小尺度侧基/链节运动 → 链段微布朗运动 → 整条链质心迁移。
  - 温度升高依次激活这些运动，使线型非晶高分子经历玻璃态、高弹态和黏流态；交联会限制整链流动。

## Key Concepts

- **扩散通量 `J`**：单位面积、单位时间通过的物质量。
- **扩散系数 `D`**：表征扩散快慢的动力学参数，强烈依赖温度与机制。
- **稳态扩散**：各位置浓度不随时间改变，通量可保持恒定。
- **非稳态扩散**：浓度分布随时间演化，需用菲克第二定律。
- **柯肯达尔效应**：二元体系组元本征扩散速率不同导致惰性标记移动，证明置换扩散与空位流相关。
- **短路扩散**：沿表面、晶界或位错芯等低激活能路径的快速扩散。
- **反应扩散**：扩散组元超过固溶度后在扩散层形成新相。
- **非化学计量化合物**：因价态变化和点缺陷补偿而偏离理想化学计量比的化合物。
- **链段**：可近似独立进行协同内旋转的高分子运动基本单元。
- **玻璃化温度 `T_g`**：链段协同运动开始显著的温区；不是热力学一级相变温度。

## Mental Models

- **扩散是“驱动力 × 迁移能力”**：化学势梯度决定方向，`D` 决定体系能多快响应；两者缺一不可。
- **温度升高有双重作用**：既增加点缺陷浓度，也提高原子越过迁移势垒的概率，因此扩散通常呈强烈指数加速。
- **缺陷是高速通道但占比有限**：低温时晶界/表面扩散优势明显；高温时晶内扩散迅速增大，体积分数更大的晶内路径可能重新主导。
- **高分子状态取决于观察时间**：温度相同而加载速率不同，可得到不同的黏弹响应；时间和温度常具有等效性。

## Anti-patterns

- **认为扩散一定从高浓度到低浓度**：理想稀溶液中常成立，普遍规律应写成沿化学势降低方向。
- **把 `D` 当常数跨温度使用**：温度变化时必须通过阿伦尼乌斯关系换算。
- **忽略边界条件直接套误差函数解**：表面恒浓度、有限源和瞬时源对应不同解。
- **把晶界扩散永远视为总扩散主导**：应同时比较路径扩散系数、有效面积/体积分数与温度。
- **把 `T_g` 当熔点**：`T_g` 对应非晶链段运动变化，`T_m` 对应晶区熔融。

## Reference Tables

| 问题类型 | 控制方程/关系 | 首要检查 |
|---|---|---|
| 稳态平板扩散 | `J=-D dc/dx` | 浓度梯度和面积是否恒定 |
| 半无限体、表面恒浓度 | 菲克第二定律误差函数解 | 初始浓度、表面浓度、`x/(2√Dt)` |
| 变温扩散 | `D=D₀exp(-Q/RT)` | 温度必须用 K，`Q` 与 `R` 单位一致 |
| 尺度估算 | `x∝√(Dt)` | 加深一倍约需四倍时间 |
| 短路扩散 | `D_surface > D_gb > D_lattice`（通常） | 低温、小晶粒时贡献更显著 |

| 高分子状态 | 主要运动单元 | 宏观表现 |
|---|---|---|
| 玻璃态 | 小基团局部运动 | 硬、脆、形变小 |
| 高弹态 | 链段协同运动 | 大可逆形变、显著黏弹性 |
| 黏流态 | 整链质心迁移 | 可流动与成形加工 |
| 交联网络 | 链段可动但整链受限 | 可有高弹态，通常无真正黏流态 |

## Worked Example

某渗碳工艺在温度不变时获得深度 `x₁` 需要时间 `t₁`。若希望渗层深度达到 `2x₁`，在相同边界条件和扩散系数下：

1. 由 `x ∝ √(Dt)` 得 `x₂/x₁ = √(t₂/t₁)`。
2. 令 `x₂/x₁=2`，则 `t₂/t₁=4`。
3. 因而渗层加深一倍，需要约四倍时间，而不是两倍。
4. 若允许升温，先用阿伦尼乌斯关系求新 `D`，再按 `t ∝ x²/D` 修正；但还要检查相变、晶粒长大和表面反应是否改变原假设。

## Key Takeaways

1. 宏观扩散题先判断稳态/非稳态和边界条件，再选择菲克第一或第二定律。
2. 扩散的普遍驱动力是化学势梯度，浓度梯度只是常见特例。
3. `D=D₀exp(-Q/RT)` 与 `x~√Dt` 是温度效应和时间尺度估算的两条主线。
4. 空位、间隙、晶界和位错提供不同迁移路径；结构越疏松，通常激活能越低。
5. 反应扩散层中的相序可结合相图判断，单个相层内部允许浓度梯度，相界处浓度可突变。
6. 高分子力学状态来自不同尺度分子运动被温度/时间依次激活。
